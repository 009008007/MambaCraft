下一個世界，哪個版本？

可安裝官方清單中的全部版本：正式版、快照／愚人節版本、Beta、Alpha 與早期版本。

安裝新版本

啟動器會先搜尋並驗證本機 Java（含版本與 CPU 架構）；Apple Silicon 上使用 LWJGL 2 的舊版會優先採用 ARM64 Java 8、ARM64 原生元件、固定雜湊的 JNA 5.7.0 和 universal Objective-C bridge；其他需 Intel 原生函式庫的舊版仍需 Rosetta 2。Fabric 只適用於官方支援的版本。

下載會校驗完整性；大型檔案遇到連線失敗或持續低速時，會自動切換備援來源，再回到官方來源重試。
MODS · MODPACKS · DISCOVER

探索 Mods 與整合包

搜尋 Modrinth 專案、查看相容的 Minecraft 版本與載入器，可從已安裝版本建議中選擇或手動輸入版本；Mods 預設匯入目前選定遊戲。空白搜尋會顯示熱門推薦。

Mods 會校驗 SHA-1／SHA-512 後才寫入目標；外部遊戲會沿用原 Mods 資料夾，請先備份；載入器無法辨識時，需手動選擇實際使用的 loader。

搜尋來源：Modrinth 官方；官方來源失敗時嘗試 MCIM 備援。來源均無法使用時會提供專案頁面供手動下載。
按「搜尋／熱門推薦」開始探索。
ⓘ

Modrinth 為主要內容來源。MCIM 是中國大陸的非官方快取鏡像，僅作連線備援；不同網絡、專案授權與快取狀態會影響可用性。整合包一鍵匯入會建立獨立實例，不會覆蓋現有世界；目前支援原版與 Fabric 的 .mrpack。其他載入器整合包可下載到 Downloads 後交由原平台匯入。

安裝位置

加入基岩版遊戲

選擇你有權使用的 Minecraft Android 安裝包，MambaCraft 會自動辨識版本與架構。支援完整 APK，或含 base／split APK 的 XAPK、APKS、APKM、ZIP。

選擇已下載的遊戲安裝檔，版本會自動辨識；不用手動改檔名。

檔案格式與進階說明

分割 APK 請同時選齊 base 與此 Mac 對應的 split。Apple Silicon 需要 arm64-v8a；Intel 需要 x86_64。OBB 暫不支援。

BACK ON TRACK
讓問題有答案。
先查看錯誤，再決定修復。世界不會被修復程序刪除。
暫時沒有載入日誌。
遇到問題時
Mods／整合包：到「Mods 與整合包」搜尋或看熱門推薦，按 Minecraft 版本和載入器選相容版本。Minecraft 版本欄會建議已安裝版本並允許手動輸入；Mod 預設匯入目前選定遊戲，也可改存 Downloads；Modrinth .mrpack 可下載，或一鍵建立獨立 Vanilla／Fabric 實例。下載先校驗 SHA-1／SHA-512；官方來源失敗時嘗試 MCIM 鏡像，兩者失敗會提供專案頁面供手動下載。
下載失敗：確認網絡及磁碟空間後重試。已校驗的檔案會保留。
遊戲閃退：先按「檢查及修復」。使用 Fabric 時，暫時移走新增的模組，再看日誌。
Java 版本：在「玩家與設定」選擇 Java 搜尋／安裝資料夾並查看建議位置；啟動器依遊戲 metadata 精確比對 Java 主版本和 CPU 架構，例如需要 Java 17 時不會誤用 Java 25；外部遊戲缺少相應 Java 時會先詢問，確認後才安裝。Apple Silicon 上使用 LWJGL 2 的版本會採用 ARM64 Java 8、固定校驗的 ARM64 原生庫、JNA 5.7.0 與 universal Objective-C bridge；GitHub 下載失敗時會嘗試固定雜湊驗證的 HTTPS 備援來源；其他需 Intel 原生函式庫的版本仍需 Rosetta 2。
想完全離線：先在線完成安裝並成功進入世界一次，正常退出，再關 Wi-Fi 測試。
遊戲管理：在「遊戲管理」查看安裝、存檔、Mods 與 Java 路徑；可開啟相應資料夾、備份或刪除 MambaCraft 管理的實例。刪除會移除該實例的世界、Mods 與設定；外部實例由原啟動器管理。
Microsoft 登入：使用 Microsoft 網頁代碼登入；密碼不會傳給啟動器。啟動前會檢查 Minecraft Java & Bedrock Edition 擁有權。
關閉介面：關閉最後一個啟動器分頁後 Helper 會自動退出；若下載工作還在進行會等工作完成；若 Minecraft 還在運行會等遊戲結束。
1.12.x 沒有視窗：RC8 會把 universal libjcocoa.dylib 放入這次遊戲的原生函式庫路徑，並記錄在遊戲日誌。若仍沒有視窗，保持遊戲運行、匯出診斷包並附上該次遊戲日誌；音樂或 Java PID 不代表啟動成功。
版本狀態：1.3 RC22 新增本地玩家清理與皮膚站登入憑證移除說明，保留世界資料。基岩版仍屬相容性預覽；macOS 實機進入世界驗證尚未完成。
